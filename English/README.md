# Guide index

The sections below form a continuous sequence from media preparation to desktop configuration. Each page identifies its starting state, commands and the result required for the next stage.

## Installation sequence

| Order | Section | Content |
| --- | --- | --- |
| 1 | [Preparation](https://github.com/guihn/ArchLinux-Installation/tree/main/English/Preparation) | Preparation of installation media and firmware boot selection. |
| 2 | [Installation](https://github.com/guihn/ArchLinux-Installation/tree/main/English/Installation) | UEFI and BIOS/Legacy routes, disk layout, base system, accounts, GRUB and the first restart. |
| 3 | [Post&nbsp;Installation](https://github.com/guihn/ArchLinux-Installation/tree/main/English/Post%20Installation) | Network, mirrors, AUR, graphics drivers, desktop packages, shell and services. |
| 4 | [Hyprland](https://github.com/guihn/ArchLinux-Installation/tree/main/English/Hyprland) | Modular configuration, monitors, input, appearance, shortcuts, workspaces and idle behavior. |
| 5 | [Customization](https://github.com/guihn/ArchLinux-Installation/tree/main/English/Customization) | Optional terminal, application startup, special workspace and theme preferences. |

## Configuration files

[Hyprland Configuration](https://github.com/guihn/ArchLinux-Installation/tree/main/English/Hyprland/Configuration) contains the twelve complete files intended for `~/.config/hypr/`, with explanations, expandable contents and links to each file. The Hyprland steps distinguish session requirements from optional personal preferences.
