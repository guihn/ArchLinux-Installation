# ArchLinux Installation

ArchLinux Installation documents a personal installation and configuration of Arch Linux with Hyprland. The guide explains each stage from installation media to a graphical session, including the purpose of commands, the expected result and the settings that depend on the computer.

The reference setup combines Linux Zen, GRUB, ext4, NetworkManager, Zsh, Neovim and foot. Its hardware includes an AMD Ryzen 9 9900X, an NVIDIA GTX 750 Ti, integrated AMD graphics, 32 GiB of RAM and two monitors. Hardware identifiers and personal choices are reference values; the relevant steps explain their selection and alternatives.

## Guide coverage

- Installation media and firmware boot selection.
- Complete UEFI and BIOS/Legacy installation procedures.
- Partitioning, formatting, system configuration, user accounts and the first boot.
- Package management, graphics drivers, initramfs generation and desktop services.
- Complete Hyprland configuration files, with their contents and download links.
- Optional personal customization, troubleshooting and technical references.

## Reading order

The [guide index](https://github.com/guihn/ArchLinux-Installation/tree/main/English) introduces the sections in execution order. [Preparation](https://github.com/guihn/ArchLinux-Installation/tree/main/English/Preparation) begins the procedure. [System Profile](https://github.com/guihn/ArchLinux-Installation/tree/main/English/System%20Profile) supplies optional hardware and software context outside that sequence.

The installation examples identify their execution environment: the temporary Live system, the installed system accessed through chroot, or the system after boot. Formatting and partition changes affect the selected storage device; backup and device identification accompany the relevant steps.
